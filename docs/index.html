BaseRT, inside your 4D application

This component wraps BaseCompute's BaseRT, a Metal-based local inference runtime. It resolves model downloads, constructs basert-serve arguments, manages the background process, and terminates it when your application exits. It is not llama.cpp and does not use GGUF models.

Apple Silicon only. The supported component target is macOS ARM64. The new source tooling targets macOS 15+. Windows, Linux and Intel macOS component builds are not provided. Model support and memory requirements come from the pinned upstream runtime, not this wrapper.

Installation

  1. Use a compatible 4D version (the package targets 4D 20.7 ARM; the project dependency format is version 2100, so use 4D 21+ for source dependency resolution).
  2. Install the component from Releases or open the source project under BaseRT/Project. Binary publishing requires actual upstream redistribution permission.
  3. Resolve the declared tcp, workers and event dependencies. They are separate components, not built-in 4D classes.
  4. Build/stage the native server before compiling a component and select it with the source_runtime option. The engine is proprietary and must be obtained separately.

Without source_runtime, the adapter retains the bundled legacy basert-serve, falling back to PATH if absent. Those committed binaries are not claimed to be current source builds.

Quick start

In the host application's startup code, choose a compatible upstream-format .base model. This example uses a third-party model repository; review its license and allow enough disk space and unified memory.

var $home : 4D.Folder
$home:=Folder(fk home folder).folder(".BaseRT")
$home.create()

var $event : cs.event.event
$event:=cs.event.event.new()
$event.onError:=Formula(ALERT($2.message))

var $chat : cs.event.huggingface
$chat:=cs.event.huggingface.new($home; \
  "keisuke-miyako/Qwen3.5-2B-basert"; "Qwen3.5-2B-Q8.base")
var $models : cs.event.huggingfaces
$models:=cs.event.huggingfaces.new([$chat])
var $options : Object
$options:={\
  source_runtime: Folder("/absolute/path/to/BaseRT/.build/runtime"); \
  engine_dir: Folder("/absolute/path/to/licensed/engine"); \
  max_tokens: 4096; max_context: 8192}

var $BaseRT : cs.BaseRT.BaseRT
$BaseRT:=cs.BaseRT.BaseRT.new(8080; $models; $home; $options; $event)

In onExit:

var $BaseRT : cs.BaseRT.BaseRT
$BaseRT:=cs.BaseRT.BaseRT.new()
$BaseRT.terminate()

Runtime and options

The first existing model file is positional; additional files in a collection use repeated --model arguments. Other keys map from snake_case to --kebab-case. Numeric/text values add an argument; true booleans emit a flag. This translation does not validate whether upstream accepts a flag: check the built server's --help.

Do not pass llama.cpp flags such as n_gpu_layers, ctx_size, jinja, models_dir or models_preset. The legacy router branches in the component are not supported BaseRT features.

CallbackMeaning
onErrorPort preflight or download error.
onData / onResponseModel-download progress/completion.
onSuccessLaunch requested, not verified HTTP/model readiness.
onTerminateThe native process exited.

Wait for the server to be ready before inference. A registered worker or a free TCP port alone is not proof of readiness. Detailed class behavior is documented in the class reference.

Support and licensing

Report component/process issues to miyako/BaseRT; report engine/model compatibility issues to upstream, including your source revision, macOS/Xcode version and model information.

The wrapper uses Apache-2.0. Runtime and third-party notices must accompany native builds; see build licensing. Model weights have their own licenses.
